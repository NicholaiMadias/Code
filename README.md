# AI-University-Java
Modern Java rebuild of the AI-University presentation starter

## Toolbox and Arcade

Small tools (`toolbox/`, reverses its arguments) and a dice game (`arcade/`) in five languages.

| Language   | Toolbox                                        | Arcade                              |
|------------|------------------------------------------------|-------------------------------------|
| Java       | `java toolbox/Toolbox.java hello`              | `java arcade/Arcade.java`           |
| PowerShell | `pwsh toolbox/toolbox.ps1 hello`               | `pwsh arcade/arcade.ps1`            |
| C#         | `dotnet run --project toolbox/csharp -- hello` | `dotnet run --project arcade/csharp`|
| TypeScript | `npx tsx toolbox/toolbox.ts hello`             | `npx tsx arcade/arcade.ts`          |
| Ruby       | `ruby toolbox/toolbox.rb hello`                | `ruby arcade/arcade.rb`             |
